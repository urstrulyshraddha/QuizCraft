# QuizCraft 🌿

A clean, interactive quiz game built with modern C++ OOP on the backend and paired with an aesthetic botanical web frontend hosted via GitHub Pages.

---

## 🎯 What It Does

QuizCraft runs customized MCQ quiz sessions across multiple participants and calculates consolidated scores at the end.

* **4 Subject Domains:** Choose between **C++ Programming**, **Environmental Sciences**, **General Knowledge**, and **History**.
* **Dynamic Randomized Sets:** Generates a randomized subset of 10 to 15 questions per candidate so no two attempts feel identical.
* **Skip Support:** Candidates can skip tricky questions without taking penalty marks.
* **Multi-Student Sessions:** Run evaluations for one student or an entire batch back-to-back in a single session.
* **End-of-Quiz Scoreboard:** Automatically compiles a clean summary table showing Registration Numbers, Names, Correct answers, Wrong answers, Skips, and Final Scores.
